# 类别归一化S2开发试验（2026-09-30）

结论：**HOLD，不采纳**。在原一帧、8样本、事件上限128与24条开发轨迹上，将总S2约束替换为同状态MW归一化后的类别S2比值之和约束；总体S1目标不变，允许类别间补偿。

- 均值流时间相对MW下降 **3.35%**，弱于原方案7.79%；P90反而增加 **2.38%**（67.349→68.954秒），原方案为下降12.36%。
- gpu_a、负载0.8，900时刻未完成数 **35（MW）→42（原方案）→45（新方案）**。node007、负载0.95新增900和1200时刻P90失败，1200时刻109.005→142.887秒。
- node007同组的LLM均值53.187→36.931秒，但JAX均值117.491→167.652秒。类别归一化继续产生延迟转移，没有带来满足门槛的性能增量。
- 实际偏离MW1571次，其中779次提高原始总S2；所有新增逐类别累加及75,365次归一化除法均计费。8项语义测试、全部24条MW复现与评分/预算检查通过；7283个评估作业在1200前全部完成。

局限：三个已见开发种子，归一化人口仅包括当前未入场作业及规划新到达；已入场作业不参与分母，但完整lane承诺保留。该指标不提供真实P90保证，计算未进入服务时钟。未开展新种子确认，论文未修改。

下一步：停止调整窗口、归一化及S2代理规则，恢复原总S2门槛。固定原目标作业人口（当前等待及一帧内预测到达），让窗口之后的背景新作业继续到达并参与MW资源竞争，直到目标作业全部入场；目标作业的完整完成时间计入S1/S2，背景作业只影响竞争。各根共享同一预测到达前缀，总未来事件上限仍128，任一分支溢出整次回退MW并保留已耗费用。该实验单独检验停止背景到达的续跑假设，沿原24条性能门槛判断。
